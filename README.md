# VORYNQ — Sistema de Barra

Punto de venta para varias barras sincronizadas en tiempo real con Firebase.

- `index.html` — barra: cobro, tickets, stock, retiros, ventas y anulación, cierre, carga de carta por Excel.
- `vorynq-dashboard.html` — panel de organizadores: recaudación, filtros, ranking, stock, exportar Excel, copia de seguridad.

Barra: https://fefojuarez.github.io/vorynq/
Panel: https://fefojuarez.github.io/vorynq/vorynq-dashboard.html

Datos en Firebase: proyecto propio `vorynq-79e90`, sección `vorynq`.
Reglas de Firebase: ver `firebase-reglas.json` (no se sube a GitHub, se pega en la consola de Firebase).
